Correct a memory by id

An edit here is the same journaled write the update_memory tool performs: the text, its vector and the hidden before-state commit together, and the history page shows exactly what changed. Leave Tags empty to keep the tags a memory already has — clearing them is the box, not the blank.

The revision above is the number this page read for that row. If the memory changed since, the edit is refused and you are told to reload — it does not overwrite the change you did not see.

Move a memory by id

A move keeps the memory's id and re-parents its partition-local cluster membership: the cluster it leaves gets the centre of the members that stay, and it joins (or forms) a cluster of the partition it arrives in. It does not carry the hidden history snapshots, the source documents or the session links with it, and it does not write a quarantine — filing is not hiding.

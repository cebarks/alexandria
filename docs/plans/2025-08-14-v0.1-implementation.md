# Alexandria v0.1: End-to-End Thin Slice — Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** Build a single-user MCP memory server that can store, embed, cluster, and recall memories with scoping-in — proving the core architecture end-to-end.

**Architecture:** Cargo workspace with 5 crates. SurrealDB embedded (SurrealKV) for storage, candle for local embeddings, rmcp for MCP server. Single-user mode — no multi-tenancy, no auth, no background pipeline. Embedding happens inline at write time.

**Tech Stack:** Rust 1.88+ (required by rmcp), tokio, SurrealDB 3.2 (embedded), rmcp 3.1, candle 0.11, tokenizers 0.22

**Simplifications for v0.1 (deferred to later milestones):**

- No multi-tenancy (single SurrealDB database, no namespace/database scoping)
- No auth/identity layer
- No background enrichment pipeline (embedding is inline at write time)
- No extract stage (users provide facts directly)
- No relate/consolidate stages
- No spreading activation (just direct heat on access)
- No cluster splitting/merging (only assignment)
- No import_document or update_memory tools
- No OpenAI embedding provider (local candle only)

**Prerequisites:**

- Rust 1.88+ toolchain (required by rmcp 3.1 which uses edition 2024)
- Verify with `rustc --version` before starting

```rust
use surrealdb::engine::local::{Db, Mem};
use surrealdb::Surreal;
use anyhow::Result;

pub struct Database {
    db: Surreal<Db>,
}

impl Database {
    /// Connect to an in-memory embedded SurrealDB instance
    pub async fn connect_embedded() -> Result<Self> {
        let db = Surreal::new::<Mem>(()).await?;
        db.use_ns("alexandria").use_db("default").await?;
        Ok(Self { db })
    }

    pub fn is_connected(&self) -> bool {
        true // embedded connection is always valid after construction
    }

    pub fn inner(&self) -> &Surreal<Db> {
        &self.db
    }
}
```

```rust
async fn test_candle_similar_texts_have_high_similarity() {
    let provider = CandleProvider::new(
        "sentence-transformers/all-MiniLM-L6-v2",
        "cpu",
    ).await.unwrap();

    let vectors = provider.embed(&[
        "OAuth tokens expire after 7 days",
        "authentication tokens have a 7 day expiry",
        "the weather is sunny today",
    ]).await.unwrap();

    let sim_related = cosine_similarity(&vectors[0], &vectors[1]);
    let sim_unrelated = cosine_similarity(&vectors[0], &vectors[2]);
    assert!(sim_related > sim_unrelated);
}

fn cosine_similarity(a: &[f32], b: &[f32]) -> f32 {
    let dot: f32 = a.iter().zip(b).map(|(x, y)| x * y).sum();
    let norm_a: f32 = a.iter().map(|x| x * x).sum::<f32>().sqrt();
    let norm_b: f32 = b.iter().map(|x| x * x).sum::<f32>().sqrt();
    dot / (norm_a * norm_b)
}
```

```rust
use rmcp::{
    handler::server::wrapper::Parameters,
    schemars, tool, tool_router,
    ServiceExt, transport::stdio,
};
use std::sync::Arc;

#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct DeleteMemoryParams {
    #[schemars(description = "The memory record ID to delete")]
    pub id: String,
}

#[derive(Clone)]
pub struct AlexandriaServer {
    db: Arc<Database>,
    embedding: Arc<dyn EmbeddingProvider>,
}

#[tool_router(server_handler)]
impl AlexandriaServer {
    #[tool(description = "Soft-delete a memory by ID")]
    async fn delete_memory(
        &self,
        Parameters(params): Parameters<DeleteMemoryParams>,
    ) -> String {
        match self.db.repos().soft_delete_fact(&params.id).await {
            Ok(_) => format!("Deleted memory {}", params.id),
            Err(e) => format!("Error: {}", e),
        }
    }
}
```

**Step 2: Wire up stdio transport**

```rust
pub async fn serve(server: AlexandriaServer) -> anyhow::Result<()> {
    let service = server.serve(stdio()).await?;
    service.waiting().await?;
    Ok(())
}
```
